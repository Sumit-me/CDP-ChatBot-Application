## CDP Assistant ##
A conversational AI assistant for Customer Data Platforms (CDPs).
CDP Assistant is a web-based application that provides helpful and practical answers to questions about Customer Data Platforms (CDPs). The assistant is built using React, TypeScript, and OpenAI's API.

App link: https://magenta-croissant-7f8267.netlify.app/

# Features #
* CDP Selection: Users can select a specific CDP (Segment, mParticle, Lytics, or Zeotap) or choose to ask questions about all CDPs.
* Conversational Interface: Users can ask questions and receive answers in a conversational format.
* API Key Management: Users can update their OpenAI API key to use the assistant.
* Footer Links: Links to CDP documentation are provided in the footer.
